# SECS/GEM 协议示例

半导体设备通信标准（SEMI E4/E5/E30/E37）示例代码。

## 计划内容

- [ ] HSMS 传输层：主动/被动连接、状态机（NOT CONNECTED / CONNECTED / SELECTED）
- [ ] SECS-II 消息编解码：Item 类型（L/A/B/U1-U8/I1-I8/F4/F8/Boolean）
- [ ] GEM 设备模型：通信状态、控制状态（Online/Offline）、报警、事件上报
- [ ] 常用消息：S1F13/14（建立通信）、S1F3/4（状态变量）、S5F1/2（报警）、S6F11/12（事件）、S2F41/42（远程命令）
- [ ] 对接 SEComSimulator 模拟器演示
