# protocol-demo

通信协议 Demo 项目：**Modbus / SECS (GEM/HSMS)** 示例代码。

## 目录结构

```
protocol-demo/
├── Modbus/   # Modbus 协议示例（RTU / TCP）
└── SECS/     # SECS/GEM 协议示例（SECS-I / HSMS / SECS-II / GEM）
```

## 说明

- 本仓库用于存放通信协议的学习与示例代码
- Modbus：工业现场总线协议（RTU 串口 / TCP 以太网）
- SECS：半导体设备通信标准（SEMI E4/E5/E30/E37），含 HSMS 传输、SECS-II 消息、GEM 设备模型
- 各协议目录内均附 README 说明使用方式

## 环境

- 语言：C# / .NET（上位机方向）
- 平台：Windows
